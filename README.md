# Trading Terminal

A professional order flow monitor with AI sentiment analysis built for active traders.

## Features
- Live order flow monitoring with audio alerts
- Multi-ticker support
- Buy/Sell ratio bar
- Large trade alerts 1000+ shares
- AI-powered news sentiment analysis
- Reddit WallStreetBets sentiment scoring
- Auto-save trading sessions
- Supports Massive and DTN IQFeed

## Installation
1. Install Python from python.org
2. Run: pip install websocket-client openai
3. Run: py orderflow_gui.py

## API Keys
- Massive API key from massive.com
- OpenAI API key from platform.openai.com
